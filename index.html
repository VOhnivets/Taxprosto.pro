Завантажте довідку про доходи

PDF-довідка «Відомості з Державного реєстру фізичних осіб — платників податків» (форма F1419104) з Електронного кабінету або Дії. Файл обробляється локально у вашому браузері.

Перетягніть PDF сюди або натисніть, щоб вибрати файл дані не передаються на сервер

Перш ніж почати
  • Це не податкова консультація. Відповідальність за зміст і подання декларації — на вас (ст. 17, 179 ПКУ).
  • Якщо протягом року були лише доходи від податкових агентів (типова зарплата з утриманим ПДФО/ВЗ) — декларацію можна не подавати (п. 179.2 ПКУ), крім випадків, прямо передбачених розд. IV ПКУ (знижка, іноземні доходи тощо).
  • MVP заповнює зарплату код 101 (рядки 10.1 / 10.3), цивільно-правові / гіг код 102 (10.2 / 10.3) і не оподатковувані проценти за держ. ЦП код 129 (рядок 11.3). Іноземні доходи, ФОП, податкова знижка, додатки Ф1/Ф2 — поза цим MVP.

Перевірте дані

Дані витягнуто автоматично. Перевірте та за потреби виправте перед генерацією XML.

Платник податку

10.1 — звичайна зарплата (ПДФО 18%), код 101

10.2 — цивільно-правовий договір (ПДФО 18%), код 102

Звичайна винагорода за ЦПД. Гіг-контракт Дія Сіті зі ставкою 5% сюди не кладіть — він у блоці 10.3.

10.3 — резидент Дія Сіті (ПДФО 5%), коди 101 / 102

Зарплата працівника або винагорода гіг-спеціаліста резидента Дія Сіті (ст. 170.14-1 ПКУ). Ліміт пільгової ставки — еквівалент 240 000 євро на рік; перевищення декларується окремо (18%).

11.3 — не оподатковувані доходи (код 129, пп. 165.1.2 ПКУ)

Проценти на державні цінні папери / боргові зобов’язання НБУ. Самі по собі не створюють обов’язку подати декларацію.

Реквізити декларації

Обов’язкові для валідного XML за XSD ДПС. Коди регіону/району та адреси в довідці немає — заповніть вручну (Електронний кабінет може уточнити їх за реєстром при імпорті).

  • Структура XML звірена з офіційною XSD ДПС F0100215 (ред. наказу МФУ №119 від 26.02.2025). Обов’язкові поля перевіряються перед генерацією; арифметику контрольних співвідношень (рядки зобов’язань 20+) цей MVP не обчислює.

  • Покриття: код 101 → 10.1 / 10.3; код 102 → 10.2 / 10.3; код 129 → 11.3. Інші коди з довідки в XML не включаються.

  • ПДФО 5% — спецрежим Дія Сіті (ст. 170.14-1 ПКУ). ВЗ з 01.10.2024 — 5% (Закон №3817-IX), у тому числі для Дія Сіті.

  • Перевірте коди регіону/району (C_REG/C_RAJ) та адресу — їх немає в довідці.
