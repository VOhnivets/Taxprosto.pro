# taxprosto.pro

Client-side заповнення **Податкової декларації про майновий стан і доходи (F0100215)** з PDF-довідки F1419104. Дані не залишають браузер.

**Live:** https://taxprosto.pro/

## Що вміє MVP

1. Завантажуєте довідку «Відомості з ДРФО» (Дія або Електронний кабінет).
2. Перевіряєте витягнені суми.
3. Отримуєте XML windows-1251 для імпорту: cabinet.tax.gov.ua → «Звітність» → «Імпорт».

| Код 4ДФ | Рядок декларації |
|---|---|
| 101, ПДФО ≈18% | 10.1 зарплата |
| 102, ПДФО ≈18% | 10.2 цивільно-правовий договір |
| 101 або 102, ПДФО ≈5% | 10.3 Дія Сіті (ст. 170.14-1 ПКУ) |
| 129 | 11.3 не оподатковувані проценти за держ. ЦП (пп. 165.1.2 ПКУ) |

Не покрито: іноземні доходи, ФОП, податкова знижка, додатки Ф1/Ф2, рядки зобов’язань 20+.

Якщо протягом року були лише доходи від податкових агентів з утриманим ПДФО/ВЗ — декларацію можна не подавати (п. 179.2 ПКУ).

Це не податкова консультація.

## Локальний запуск

```bash
python3 -m http.server 8080
# http://localhost:8080/
```

Потрібен сучасний браузер (ES-модулі, `crypto.subtle`). Для перевірки воркера pdf.js сторінка має бути на `http://localhost` або HTTPS.

## Перевірка логіки (без браузера)

```bash
node tests/run.mjs
```

Потрібен `xmllint` (`libxml2-utils`) і схеми в `knowledge/xsd/`.

## Безпека

- pdf.js 4.10.38, `isEvalSupported: false` (CVE-2024-4367)
- CSP у `<meta>`, SRI на модуль pdf.js, SHA-384 воркера в runtime
- Рядки з PDF екрануються перед вставкою в DOM
- Немає бекенда і аналітики
